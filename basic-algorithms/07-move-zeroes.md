# Problem: Move Zeroes (Easy–Medium)
**Link:** [Official LeetCode Problem](https://leetcode.com/problems/move-zeroes/)

## Approach
Scan the array and move each nonzero value to the next available position, swapping in place. The relative order of nonzero values is preserved, and the remaining positions naturally contain zeroes.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes
The test cases cover an interleaved array and an array containing only zeroes. An array with no zeroes is unchanged by the same algorithm. Accepted screenshot will be added manually after LeetCode submission.
